## Exercises

Given a text file named `text`:

1. For **practice1**, add spaces before and after each `+`.  

2. For **practice2**, wrap every word with parentheses.  

3. For **practice3**, wrap each occurrence of the word `this` with parentheses.  

4. For **practice4**, perform the following modifications:  
   - (1) Append the line number at the end of each line.  
   - (2) Replace English-written numbers with Arabic numerals (e.g., `Thirteen` → `13`).  
   _HINT: You can use `line('.')` to retrieve the current line number._  

5. For **practice5**, correct the misspelled word using copy-paste (the correct word is `line`).
